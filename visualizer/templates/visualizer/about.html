About ProbViz

An interactive educational platform for probability and statistics.

What is ProbViz?

Probability Visualizer (ProbViz) is an interactive web application designed to help students, educators, data scientists, and anyone curious about probability explore statistical concepts through beautiful interactive visualization.

With support for {{ dist_count }} different distributions — both continuous and discrete — you can plot PDFs, CDFs, histograms, compare distributions side-by-side, compute descriptive statistics, and calculate probabilities — all from your browser.

Technology Stack

  • Django 5 Backend
  • SciPy / NumPy / Pandas Statistics
  • Plotly Visualization
  • Bootstrap 5 UI Framework
  • SQLite Database
